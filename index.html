Kuasai Dasar-Dasar Pembangun Website

Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup standar untuk membuat halaman web. Anggap saja HTML sebagai kerangka atau fondasi dari setiap website yang kamu kunjungi.

  • HyperText - Teks yang memiliki tautan ke teks lainnya
  • Markup - Proses menambahkan tag pada teks untuk menentukan struktur dan maknanya.
  • Language - Kumpulan aturan dan sintaks untuk membuat dokumen HTML.

Cara Kerja HTML

HTML menggunakan tag untuk mendefinisikan elemen, yang ditulis di dalam tanda kurung siku (< >).

Struktur Dasar HTML

Setiap dokumen HTML mengikuti struktur dasar berikut:

  1. <!DOCTYPE html> - Menyatakan tipe dokumen dan versi HTML yang dipakai.
  2. <html> - Elemen utama (root) yang membungkus seluruh isi.
  3. <head> - Berisi informasi meta, judul, serta tautan ke stylesheet atau script.
  4. <body> - Berisi konten yang tampil di halaman web.

Tag HTML yang Penting

Tag Fungsi Contoh
<h1> - <h6> Judul/heading (dari terbesar sampai terkecil) <h1>Judul Utama</h1>
<p> Paragraf <p>Teks paragraf</p>
<a> Tautan (link) <a href="url">Teks Link</a>
<img> Gambar <img src="gambar.jpg" alt="Deskripsi">
<div> Wadah / bagian <div>Isi</div>
<ul>, <ol>, <li> Daftar (list) <ul><li>Item</li></ul>

Formulir HTML

Atribut HTML

Atribut memberikan informasi tambahan tentang elemen HTML.

Atribut Penting:

  • id - Pengenal unik untuk sebuah elemen
  • class - Mengelompokkan elemen untuk keperluan styling
  • src - Sumber file untuk gambar, video, dan sejenisnya
  • href - Alamat URL untuk tautan
  • alt - Teks alternatif untuk gambar
  • style - Styling CSS secara inline

Tabel di HTML

Tabel digunakan untuk menyusun data dalam baris dan kolom:

Contoh Tabel:

Mahasiswa Mata Kuliah Nilai Status
Alice Johnson Matematika A+ Lulus
Bob Smith Fisika B Lulus
Carol Davis Kimia A Lulus

Latihan Soal

  2. Tambahkan gambar lengkap dengan teks alt
  3. Buat daftar film favoritmu

Tingkat Menengah:

  1. Buat formulir kontak dengan berbagai jenis input
  2. Buat menu navigasi dengan beberapa tautan
  3. Rancang tata letak postingan blog sederhana

Langkah Selanjutnya dalam Belajarmu

Setelah menguasai HTML, lanjutkan dengan mempelajari:

  • CSS (Cascading Style Sheets) - Mengatur tampilan elemen HTML
  • JavaScript - Menambahkan interaksi dan perilaku dinamis
  • Responsive Design - Membuat website nyaman dibuka di semua perangkat
  • Web Accessibility - Membuat website bisa digunakan oleh semua orang
  • Framework Modern - React, Vue.js, atau Angular
